# ECM and Gibbs sampler for group-tested current status data

Reproducibility code for the paper *"ECM and Gibbs Sampler for Regression Analysis of
Group-Tested Current Status Data under the Semiparametric Probit Model."*

Two estimators are provided for the same semiparametric probit model, with the baseline
transformation function approximated by monotone I-splines:

- **ECM algorithm** — a frequentist estimator (`ECM.R`)
- **Gibbs sampler** — a Bayesian estimator (`Gibbs.R`)

The scripts reproduce the simulation study (Tables 1–4, Figures 1–2) and the real-data
application (Table 5, Figure 3). The competing method of Fang et al. (2027) is included for
comparison.

## Requirements

- R (≥ 4.0)
- R packages: `truncnorm`, `mvtnorm`, `xtable`

```r
install.packages(c("truncnorm", "mvtnorm", "xtable"))
```

Run every script with the repository root as the working directory; all paths are relative
to it. Output folders (`simulation/results/…`) are created automatically.

## Layout

```
ECM.R                     ECM() estimator            (function library)
Gibbs.R                   Gibbs() sampler            (function library)

sim_1_data_generation.R   generate 12,000 datasets      -> DATA.rds
sim_2_ECM.R               ECM over all datasets         -> simulation/results/ECM/
sim_3_Gibbs_array.R       Gibbs over all datasets       -> simulation/results/Gibbs/
sim_4_Fang.R              Fang et al. over all datasets -> simulation/results/Fang/
sim_5_summarize.R         Tables 1-4 + timing/NA        -> simulation/results/tables.tex
sim_6_baseplots.R         Figures 1-2 (baseline S0)     -> baseplot1.png, baseplot2.png

real_1_ecm_gibbs.R        ECM + Gibbs on chlamydia data -> table5_{ecm,gibbs}.csv, realplot_final.png
real_2_fang.R             Fang et al. on chlamydia data -> table5_fang.csv

fang_code/                Fang et al. (2027) estimator, adapted (see note below)
```

`ECM.R` and `Gibbs.R` are `source()`-d by the drivers; run the numbered scripts in order.

## Running the simulation study

```bash
Rscript sim_1_data_generation.R   # writes DATA.rds (12,000 datasets)
Rscript sim_2_ECM.R               # ECM  -> simulation/results/ECM/
Rscript sim_3_Gibbs_array.R       # Gibbs -> simulation/results/Gibbs/
Rscript sim_4_Fang.R              # Fang  -> simulation/results/Fang/
Rscript sim_5_summarize.R         # Tables 1-4, timing and convergence summaries
Rscript sim_6_baseplots.R         # Figures 1-2
```

`sim_3_Gibbs_array.R` is written for a SLURM job array (12,000 datasets in 24 batches of
500) but also runs serially; it uses forked parallelism when several cores are available.
`sim_2`/`sim_4` can likewise be batched. Settings (sample size, spline order, number of
knots, etc.) are near the top of each script.

## Running the real-data application

`real_1_ecm_gibbs.R` and `real_2_fang.R` expect the chlamydia dataset in the working
directory. **The data are not included** (see Data availability); with the file present:

```bash
Rscript real_1_ecm_gibbs.R        # ECM + Gibbs -> Table 5 columns, Figure 3
Rscript real_2_fang.R             # Fang et al. -> Table 5 column
```

## Data availability

- **Simulated data** are generated by `sim_1_data_generation.R` (seeded); `DATA.rds` and all
  `simulation/results/` outputs are reproducible and are not stored in the repository.
- **Chlamydia data** are from the Nebraska Public Health Laboratory and are not publicly
  redistributable; they are not included here. Requests should be directed to the data provider.

## The Fang et al. (2027) comparison

`fang_code/` adapts the estimator of Fang et al. (2027) to the group-tested current status
setting used here. `Support_functions_matched.R` fixes the spline specification to match the
proposed methods (degree 3, 10 equal-probability quantile knots) for a controlled comparison;
`Support_functions_fixed.R` is used for the real data. The underlying method is due to
Fang et al.; please cite their work when using this part.
